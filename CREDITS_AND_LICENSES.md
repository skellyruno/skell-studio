## Upstream projects

- [ADE Studio](https://github.com/ajdohaxhia/ADE-Studio): integrated base from the exact `ADE-Studio-michael-lane.zip` snapshot supplied by the user.
- [ML Studio](https://github.com/Dorfhaus/ML-Studio): input reference from the exact `ML-Studio-michael-lane.zip` snapshot, with nine unique files retained separately.

Skell-specific UI, palette, skull icon and startup changes were added November 12, 2026. The current UI skull is a provisional design pending the final shared SkellCore asset.
