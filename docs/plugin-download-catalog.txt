LEMON STUDIO - PLUGIN DOWNLOADS
Catalog checked 2 November 2026

93 free plugins: 59 open-source entries and 34 freeware entries.
All ten original categories retain at least five entries. Every new entry has a
direct official Windows download: no account, checkout or download manager.
This is a curated selection, not a claimed worldwide popularity ranking: makers
publish incomparable usage figures. Established projects were prioritized, then
specialist tools were selected for category coverage, clear source licenses and
free official binary downloads without an account or subscription.

Use the download-arrow icon in Lemon Studio's browser. Expand a category or
search by plugin name/type. Click a row to see its preview, version, size, source
and license; click its download arrow or the action button to download.
Hover over a plugin for a short information card explaining its purpose, useful
applications and any free-edition limitations. Nothing downloads on hover.

WINDOWS: 18 portable entries install into this Lemon Studio profile and start a
plugin scan automatically. The other 75 open the maker's installer or archive. Finish its
installation, then click Scan Plugins. No silent installer/elevation is used.
MAC/LINUX: compatible official installers or archives open after downloading.
Install the VST3, CLAP or VST2 plugin, then Scan Plugins. For a manually extracted
archive, add its extracted plugin folder in Settings > Plugins if needed.
Linux .deb installers are for Debian/Ubuntu; other distributions need a suitable
package handler or manual extraction. Universal/architecture-specific Mac builds
are selected explicitly. oXygen has no native Apple Silicon download in this set.

Packages stay in the active profile's Plugin Downloads folder. The Downloads
button opens it. Source and License open the author's pages. Downloads are on
demand; browsing needs no network connection. The catalog does not change your
sample folders, favorites, personal plugin organization or startup template.

The original 127 unique official download URLs and all 56 new official packages
were retrieved and SHA-256 hashed (183 total). The
original catalog pins those exact bytes, so replaced/tampered downloads cannot launch.
If a maker replaces an unversioned file, a catalog update is needed; Source
provides the maker's current options. Partial downloads are never installed.
Tests exercised the application's real downloader (without opening installers),
all 18 Windows portable packages in scratch folders, repeat installation,
checksum/size/cancel rejection, category/search/click/scroll/layout behavior.
No musical quality, installer GUI, Mac runtime or Linux runtime certification is
implied. Visual and hands-on audio review remains with the user.

oXygen: Windows/Intel Mac 1.0.4, Linux 1.2.1, reflecting the author's available
binaries. Its assistant uses signal analysis, not a shipped neural inference
model. Newer screenshot/interface appearance can differ from the older binaries.
