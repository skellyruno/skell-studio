Envelope static anchors: 0x180099f60 (tick), 0x18009a3d0 (setup/retiming), 0x18008f920 (curve helper). Offline runner uses synthetic MIDI, no GUI/audio hardware.

Integration: each note selects Classic or Curved AHDSR at onset; existing time knob mappings remain unchanged. Curve and duration changes take effect at the next stage entry. Sustain remains live. Same-note polyphonic retriggers allocate another voice. No mono/legato or full reference retiming/retrigger semantics claimed. Hold/curve widgets are dimmed in Classic mode. Graph sustain interval is illustrative, because note duration is externally controlled.

Filter static anchors: 0x1802fcc90 (coefficients) and 0x1802f7510 (render). g=2*sin(pi*fc/(2*internal_rate)); resonance damping 2*(1-res^0.25), stability cap; gain 1/(4*res+1); input drive (1+drive)^4; clipped cubic input/interstage saturation. Reconstructed cases 5/7/9/11/12/13 correspond LP12/LP24/HP12/HP24/BP12/BP24. First section nonlinear, second section linear for 24 dB paths. Six offline reference comparisons at one cutoff/resonance condition fit an upstream scale near .306 and a cutoff multiplier 1.00132 with aggregate relative RMS .000113. This fit is exploratory, not an independently validated parameter law. It is NOT used as a claim of reference voice-bus parity.

Input/output gain and routing are Lemon's own. Response display is a guide, not a measured nonlinear response. Ladder, comb, notch, dual-filter routing and all other filter models remain future work.

Validation: envelope fixture regression; curve/display consistency; hold/early release; pedal release, end notification and block invariance; finite filter stress across 8/44.1/48/96/192 kHz, cutoff/resonance/drive extremes and all six models; actual CLAP/VST3 state/audio recall; 44/50/62-parameter captured legacy compatibility.
